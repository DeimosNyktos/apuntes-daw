# Apuntes de DAW1 · INS La Ferreria

Web de apuntes de primer curso de DAW con cuatro asignaturas, que se cambian con las pestañas de arriba:

- **Programación (Java):** Unidades 1 y 2: tipos de datos, variables, entrada y salida, operadores, conversiones, selección, bucles y más, con diagramas de flujo.
- **Sistemas informáticos:** numeración, hardware, redes, sistemas operativos, virtualización, Windows y Linux.
- **Lenguajes de marcas:** XML bien formado, espacios de nombres, DTD y esquemas XML.
- **Bases de datos:** modelo E-R, modelo relacional, SQL (DDL, vistas, SELECT y funciones) en Oracle.

Cada tema trae un resumen, la teoría del curso, enunciados de ejercicios y las soluciones del profe cuando existen.

**Web en vivo:** https://deimosnyktos.github.io/apuntes-java-m3/

Es un único archivo, `index.html`, sin dependencias: ábrelo con doble clic en el navegador.

## Contenido y créditos

- Los apuntes y diagramas están escritos para esta web.
- Los enunciados, ejemplos y soluciones proceden de los materiales de los módulos del INS La Ferreria. Son de sus autores y se incluyen con fines de estudio.


## Estado del proyecto

Esta web se irá actualizando según avance el curso: se añadirán los temas, ejemplos y ejercicios nuevos a medida que se vean en clase. Ahora mismo cubre las Unidades 1 y 2 de Programación, los Bloques 1 y 2 de Sistemas informáticos, la Unidad 1 de Lenguajes de marcas y los temas de Bases de datos hasta las funciones SQL.
